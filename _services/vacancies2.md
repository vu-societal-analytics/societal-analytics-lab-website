# Overview and tasks

As student assistant, you will translate a physical serious game into an online one. The serious game is an adaptation of “The AI Dilemma” [https://zenodo.org/records/20160185](https://zenodo.org/records/20160185). 
The AI Dilemma is a collaborative game designed to be played simultaneously by two to five players plus a moderator. At its core, the game should allow players to:

* Randomly select cards.
* Move their tokens across the board.
* Throw a die.
* See each others progress.

In terms of software development:

* The game should be fully documented in GitHub.
* The game should be in a Docker container, so that other institutions can easily install it.
* The game will be securely stored in a VU server. 
* Players can easily access the game via a secure browser connection and with given credentials.
* The game should be easy to adapt to other settings, e.g., it should be easy to change the text in the game cards.
