# About my project

*Internship supervisor:* [Dr. Sofia Gil-Clavel](https://www.sofiagilclavel.com/)

*Project:* Applying and Evaluating Energy Efficiency Techniques for Web Applications: 
A Case Study With a Serious Game Platform

*Abstract:* Software energy consumption is a growing sustainability concern, and 
researchers have proposed techniques to reduce it. However, most of these techniques 
were validated in large-scale cloud or mobile contexts, and some show null or 
inconsistent effects. Therefore, it remains unclear which ones work for lightweight 
REST-based web applications. This thesis uses the development of an online 
version of "The AI Dilemma", a serious game for responsible AI use, as a case 
study. We curate candidate techniques from the literature and select those relevant 
to the platform's REST-based architecture. For each selected technique, we implement 
variants with and without the techniques applied to measure their energy consumption 
in controlled experiments under repeated and standardized load. We also document 
implementation challenges and trade-offs through field notes. The thesis contributes 
an energy-profiled implementation of the platform and an evidence-based shortlist of 
techniques worth applying.
